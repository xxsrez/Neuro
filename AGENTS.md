# Инструкции для агента

## Назначение проекта

Neuro — учебный стенд для собственной небольшой глубокой нейросети на CPU.
Цели и ограничения описаны в [README.md](README.md). Сохраняй учебную
направленность: реализация должна позволять проследить вычисления и понять
причины результата.

## Реализация

- Пиши вычислительное ядро самостоятельно: операции с векторами и матрицами,
  нейроны, слои, активации, функции потерь, backpropagation и оптимизаторы.
- Не подключай готовые ML-фреймворки, библиотеки автоматического
  дифференцирования или специализированные численные библиотеки для
  реализации ядра. Используй CPU и стандартную библиотеку выбранного языка.
- Не раздувай число параметров, объём данных и время обучения без причины.
  Указывай число обучаемых параметров для каждого эксперимента.
- Предпочитай небольшие понятные компоненты. Объясняй нетривиальные формулы,
  размерности и численные ограничения рядом с реализацией.
- Добавляй механизмы постепенно: сначала проверяемая базовая реализация,
  затем варианты архитектуры и оптимизаторов.
- Не считай язык, архитектуру или набор данных выбранными, пока решение
  не принято в рамках соответствующей задачи.

## Проверка вычислений и эксперименты

- Проверяй базовые операции на примерах с известным результатом.
- Проверяй аналитические градиенты численными разностями на маленьких
  примерах с явно заданным допуском.
- Проверяй, что обучение решает выбранную маленькую контрольную задачу;
  одного успешного запуска недостаточно.
- Фиксируй начальное состояние генератора случайных чисел, архитектуру,
  данные, гиперпараметры и число шагов, чтобы опыт можно было повторить.
- При сравнении оптимизаторов сохраняй сопоставимые условия. Отделяй
  измеренные результаты от предположений; указывай условия замера времени.
- Не добавляй большие датасеты, веса, промежуточные результаты и локальные
  секреты в Git. Небольшие тестовые примеры можно хранить в репозитории.

## Работа с проектом

- На русские запросы отвечай по-русски, прямо и по делу.
- Поддерживай README в соответствии с фактическим состоянием; планы
  не описывай как уже реализованные возможности.
- Создавай и редактируй текстовые файлы через `apply_patch`; исключения —
  форматтеры, генераторы и бинарные файлы с последующей проверкой изменений.
- Сохраняй чужие незавершённые изменения. Не выполняй разрушительные
  операции и не публикуй данные за пределами разрешённого пользователем объёма.
