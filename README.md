# Neuro

Учебный экспериментальный стенд для небольшой глубокой нейросети, написанной
с нуля. Обучение и применение модели выполняются на CPU, с небольшим числом
параметров и без специализированных вычислительных библиотек.

Цель — разобраться в устройстве нейросети через собственную реализацию:
от отдельного нейрона до многослойной сети и полного цикла обучения.
Важнее понимать и проверять вычисления, чем добиваться рекордов качества
или скорости.

## Что планируется

- Собственные операции над векторами и матрицами, нейроны и слои.
- Эксперименты с функциями активации и архитектурой небольшой глубокой сети.
- Прямой проход, функции потерь и обратное распространение ошибки
  (backpropagation).
- Собственные SGD и Adam: SGD для проверки базового обновления весов,
  Adam для первого основного опыта, затем сравнение результатов.
- Обучение на небольших задачах, проверка градиентов и воспроизводимые
  сравнения результатов.

## Ограничения

- Только CPU; GPU и специализированные ускорители не требуются.
- Математика сети, вычисление градиентов и обновление параметров реализуются
  внутри проекта. Готовые ML-фреймворки, автоматическое дифференцирование,
  NumPy и аналогичные библиотеки не используются для этих вычислений.
- Стандартная библиотека языка допустима. Вспомогательные инструменты
  не должны подменять собственную реализацию нейросети.
- Размер модели и данных должен оставаться небольшим и подходить для
  локальных экспериментов на CPU. Точный бюджет параметров пока не выбран.

## Текущее состояние

Реализован локальный прототип на Go: float64, явные циклы,
только стандартная библиотека. По начальным координатам сеть предсказывает
результат 20 шагов нелинейного движения точки.

По умолчанию: ширина 20, 10 двухслойных остаточных блоков, Swish,
8 502 параметра, Adam, без BatchNorm. Доступны ReLU, tanh, Leaky ReLU и SGD.
Есть ручной обратный проход, численные проверки градиентов, журналы,
сохранение/загрузка весов и автономный HTML-отчёт.

Полный Go-запуск на 200 эпохах достиг валидационной MSE 0.000364
и тестовой MSE 0.000393. Проверки описаны в
[отчёте прототипа](docs/reports/go-prototype-2026-09-27.md).

## Запуск

Нужен Go 1.23 или новее. Внешние пакеты для обучения не требуются.
Выполнять из корня репозитория:

```sh
go test ./...
go vet ./...
go build -o build/neuro ./cmd/neuro
./build/neuro train --out runs/my-first-run
./build/neuro evaluate runs/my-first-run
```

Каталог запуска должен быть новым: существующие результаты не перезаписываются.
Отчёт создаётся в runs/my-first-run/report.html; откройте его в браузере
самостоятельно. Программа не запускает браузер и не поднимает сервер.

Короткий опыт или выбор активации:

```sh
go run ./cmd/neuro train --epochs 20 --activation Tanh --out runs/tanh-20
go run ./cmd/neuro --help
```

Параметры, файлы результатов и проверки отчёта:
[руководство по запуску](docs/guides/running.md).
Продолжение обучения из сохранённого состояния пока не реализовано:
файлы весов предназначены для оценки.
