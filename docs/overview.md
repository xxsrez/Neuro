# Обзор проекта

## Цель

Neuro — локальный учебный стенд для изучения небольшой глубокой нейросети
через собственную реализацию. Нужно видеть прямой проход, распространение
градиентов, изменение весов и причины различий между экспериментами.
Обучение и применение модели работают на CPU, без готовых ML-фреймворков,
автоматического дифференцирования и специализированных численных библиотек.

Первая задача — предсказать результат 20 шагов нелинейного движения точки
по её начальным координатам. Ответы генерируются собственным симулятором.
Планируется скрытая ширина 20 и около 10–20 внутренних обучаемых слоёв.
Точные размеры описаны в [архитектуре](architecture.md).

## Как будет выглядеть работа со стендом

1. Выбрать воспроизводимую конфигурацию: данные, глубину, активацию,
   оптимизатор и настройки обучения.
2. Сгенерировать выборки и посмотреть истинное движение точек.
3. Запустить обучение с журналом метрик и сохранением лучших весов.
4. Посмотреть кривые потерь, карту ошибок и поведение скрытых слоёв.
5. Повторить опыт, изменив один фактор, и сравнить результаты.

Реализован локальный запуск обучения на Go с сохранением результатов
в JSON/CSV и автономным HTML-отчётом. Опыт выполняется без открытого
интерфейса. Веб-сервис и размещение в интернете не требуются.

## Предполагаемые компоненты

| Компонент | Ответственность |
| --- | --- |
| Симулятор и выборки | Динамика точки, разделение данных, нормализация, генераторы случайных чисел |
| Вычислительное ядро | Векторы, матрицы, линейные слои, активации, ручной обратный проход |
| Модель | Граничные слои, остаточные блоки, параметры и промежуточные значения |
| Оптимизаторы | SGD, Adam и их состояния |
| Обучение | Пакеты, эпохи, функция потерь, проверка качества, сохранение состояния |
| Оценка и журнал | Метрики, базовые сравнения, конфигурация и время опыта |
| Визуализация | Графики потерь, ошибки на плоскости, активности и градиенты |

Ядро, модель, генератор и оптимизаторы находятся в internal/neuro/;
цикл обучения, конфигурация и создание отчёта — в internal/app/;
точка входа — cmd/neuro/. Шаблон визуализации — assets/report.html,
встроен в бинарный файл через go:embed. Go-тесты лежат рядом с кодом
в файлах *_test.go, проверки JavaScript отчёта — tests/report-check.mjs.
Результаты запусков, данные и веса храним в исключённом из Git runs/.

## Границы первой версии

Одна двумерная задача, полносвязная остаточная сеть, ручные производные,
SGD и Adam, сменные активации и локальные воспроизводимые опыты.
Не планируются GPU, распределённое обучение, универсальный тензорный
фреймворк, общий движок автоматического дифференцирования или сервис
для внешних пользователей. BatchNorm и обучение по промежуточным точкам
оставлены отдельными последующими экспериментами.

Успех стенда означает проверенные вычисления, обучение на новых точках
лучше простых контрольных моделей и понятные воспроизводимые сравнения.
Победа глубокой сети над любой короткой сетью не является обещанием.
