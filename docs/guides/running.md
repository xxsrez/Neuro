# Запуск прототипа

## Требования и проверка ядра

Go 1.23 или новее, только стандартная библиотека. Проверено с Go 1.27.1.
Node.js нужен только для дополнительного теста созданного HTML,
для обучения и просмотра отчёта он не требуется.

Из корня репозитория:

```sh
go test ./...
go vet ./...
go build -o build/neuro ./cmd/neuro
```

Тесты используют стандартный пакет testing; go test возвращает ненулевой
код при ошибке. Проверяются ручные примеры,
численные производные параметров и входа маленькой сети для всех активаций,
остаточный путь, накопление пакетов, оптимизаторы, воспроизводимость
и обучение простой контрольной задачи.

## Обучение и оценка

```sh
./build/neuro train --out runs/new-experiment
./build/neuro evaluate runs/new-experiment
```

Каталог результата должен быть новым. Программа не затирает существующие
данные. Оценка загружает best-weights.json и повторно генерирует независимые
валидационную и тестовую выборки из записанных параметров.

Параметры командной строки:

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| --width, --blocks | 20, 10 | Скрытая ширина и число двухслойных блоков |
| --activation | Swish | Swish, Relu, Tanh, LeakyRelu |
| --optimizer, --lr | Adam, 0.001 | Adam или Sgd и скорость обучения |
| --alpha | 0.1 | Масштаб остаточной ветви; ноль отключает ветвь |
| --epochs, --batch | 200, 64 | Эпохи и размер пакета |
| --train, --validation, --test | 8192, 2048, 2048 | Размеры выборок |
| --steps, --h | 20, 0.2 | Горизонт и шаг симулятора |
| --grid | 101 | Число точек на стороне карты ошибок |
| --weight-seed, --shuffle-seed | 42, 4004 | Начальные состояния весов и перемешивания |
| --train-seed, --validation-seed, --test-seed | 1001, 2002, 3003 | Независимые состояния генераторов данных |
| --out | runs/go-prototype | Новый каталог результатов |

Имена активаций и оптимизаторов принимаются без учёта регистра.
Начальные состояния генерируют поток SplitMix64; алгоритм зафиксирован
в коде. Точная побитовая повторяемость проверена в одном окружении;
между платформами реализации математических функций могут различаться.

## Результаты запуска

| Файл | Содержание |
| --- | --- |
| config.json | Все параметры запуска, включая начальные состояния |
| environment.json | Runtime, ОС, архитектура CPU, версия генераторов и Git-состояние |
| metrics.csv, history.json | Потери, расстояния и время по эпохам, включая эпоху 0 |
| best-weights.json | Веса эпохи с минимальной валидационной MSE |
| last-weights.json | Веса после последней эпохи |
| summary.json | Метрики контрольных моделей и сети, критерий первого опыта |
| report-data.json | Данные графиков, сетки, активностей и градиентов |
| report.html | Автономный отчёт: основные SVG и интерактивные Canvas |

Критерий первого опыта записывается до обучения: валидационная MSE <= 0.01
и ниже начальной ошибки, модели без движения и аффинной модели.
Поле accepted сообщает его результат. Успешное выполнение команды означает
завершение запуска; само по себе оно не означает достижение критерия.

Файлы весов не позволяют продолжить обучение с точным состоянием Adam
и генератора перемешивания. Команда evaluate предназначена только для оценки.

## Проверка и пересборка отчёта

```sh
node tests/report-check.mjs runs/new-experiment
./build/neuro report runs/new-experiment
```

Тест проверяет встроенные данные, соответствие CSV, расстояния на карте,
статическое содержимое и работу обработчиков JavaScript с тестовыми
заменителями DOM/Canvas. Он не является проверкой реального браузерного
рендеринга. Команда report пересобирает HTML из сохранённых данных без
повторного обучения; заменяет только report.html в указанном запуске.
Необязательный второй аргумент теста — каталог повторного запуска:
сравниваются все метрики по эпохам и лучшие/последние веса, исключая время.

```sh
node tests/report-check.mjs runs/go-prototype runs/go-prototype-repeat
```

Откройте report.html самостоятельно. Он не обращается к интернету.
Основные таблицы, графики и активности первого блока видны без JavaScript.
С JavaScript доступны логарифмическая шкала потерь, выбор блока и просмотр
точек карты. Добавление ?fail=1 к адресу включает явный отказ интерактивного
вида для проверки сохранности основного отчёта.
Проверка отображения на телефоне и в конкретных просмотрщиках не проводилась.
