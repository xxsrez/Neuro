# Переход Neuro на Go — 27 сентября 2026

## Что перенесено

По запросу пользователя прототип переписан с C# на Go. Текущий репозиторий
содержит Go-исходники; C#-версия сохранена в Git-коммите ff3165d.
Для сборки и обучения больше не нужен .NET. go.mod не содержит внешних
зависимостей; используются стандартная библиотека и float64.

Сохранены симулятор, нормализация, SplitMix64, ширина 20, 10 двухслойных
остаточных блоков, 8 502 параметра, Swish/ReLU/tanh/Leaky ReLU,
SGD/Adam, пакетное усреднение, выбор лучших весов по валидации и независимый
тест. CLI поддерживает train, evaluate и report. HTML-шаблон встроен
в бинарный файл через go:embed, поэтому бинарный файл не требует шаблона
в текущем рабочем каталоге.

JSON-веса formatVersion = 1 и данные отчётов совместимы с первой версией.
Продолжение обучения из checkpoint по-прежнему не поддерживается.

## Проверки

- go test ./...: 10 основных тестов ядра, включая численные градиенты
  всей маленькой сети для четырёх активаций, и 4 теста уровня приложения.
- go vet ./... и сборка бинарного файла прошли.
- Проверены пакет из 65 примеров с неполным хвостом, сохранение/загрузка
  весов, запрет перезаписи существующих запусков, конфигурация и HTML-экранирование.
- Старые C#-веса загружены в Go: выборочные предсказания на сетке совпали
  с допуском 1e-11, валидационная и тестовая MSE — с допуском 1e-12.
  Этот дополнительный тест использует локальный runs/prototype/;
  в чистом клоне без исходных артефактов он пропускается.
- Проверки данных и JavaScript отчёта используют прежний tests/report-check.mjs.
  Реальное отображение в браузере остаётся непроверенным из-за ранее
  наблюдавшегося запрета file://; запрет не обходился.

## Полное обучение с нуля

Окружение: Go 1.27.1, darwin/arm64. Конфигурация и начальные состояния
генераторов совпадают с первым C#-опытом: 200 эпох, пакет 64,
8 192/2 048/2 048 точек, Swish, Adam, lr = 0.001, alpha = 0.1.

Лучшие веса выбраны на эпохе 177; валидационная MSE около 0.0003636765,
тестовая — 0.0003931346. Аффинная модель даёт валидационную MSE 0.4168175.
Критерий первого опыта достигнут. Обучение и оценка по эпохам заняли
50.88 секунды в одном запуске, без построения конечного HTML.
Сравнение времени с C# не является контролируемым бенчмарком.

Артефакты находятся локально в runs/go-prototype/ и исключены из Git.
Источники результата — summary.json, history.json и сохранённые веса.
Данные первоначальных запусков сохраняют предшествующий Git-коммит
и dirty=true; метаданные не подменяются задним числом.

Совпадение результатов обучения в этом опыте не означает гарантии
побитовой идентичности между языками и платформами. Поведение на фиксированных
весах и повторяемость внутри одного Go-окружения проверяются отдельно.

Сравнение всех 201 оценок Go и C# показало максимальное абсолютное
расхождение метрик 9.77e-15. Отдельный повторный Go-запуск в
runs/go-prototype-repeat/ точно воспроизвёл лучшие и последние веса,
все метрики по эпохам и итоговую оценку; время составило 50.94 секунды.
Время и метаданные при проверке повторяемости исключались.

Короткие CLI-проверки ReLU/SGD, tanh/Adam и Leaky ReLU/Adam также завершились;
это проверки режимов, а не исследования качества этих вариантов.
