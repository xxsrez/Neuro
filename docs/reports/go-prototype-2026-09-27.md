# Опыт прототипа Go — 27 сентября 2026

## Конфигурация

Go 1.27.1, darwin/arm64, стандартная библиотека и float64.
Ширина 20, 10 двухслойных остаточных блоков, 8 502 параметра,
Swish, alpha = 0.1, без BatchNorm. Доступны также ReLU, tanh,
Leaky ReLU, SGD и Adam.

Генератор: 20 шагов с h = 0.2, начальные точки равномерны в [-pi, pi]²;
координаты для сети делятся на pi. Выборки: 8 192 обучающих,
2 048 валидационных, 2 048 тестовых точек. Начальные состояния SplitMix64:
1001/2002/3003 для данных, 42 для весов, 4004 для перемешивания.

Обучение: 200 эпох, пакет 64, 25 600 обновлений Adam;
lr = 0.001, beta1 = 0.9, beta2 = 0.999, epsilon = 1e-8.
Лучшие веса выбираются только по валидации, тест оценивается после выбора.

## Результат

Лучшие веса выбраны на эпохе 177. Валидационная MSE около 0.0003636765,
тестовая — 0.0003931346. Аффинная контрольная модель даёт валидационную
MSE 0.4168175. Заранее установленный критерий первого опыта достигнут:
валидационная MSE <= 0.01 и ниже начальной ошибки и обеих контрольных моделей.

Первый запуск обучения с оценкой по эпохам занял 50.88 секунды,
без построения конечного HTML. Повторный запуск — 50.94 секунды:
точно совпали лучшие и последние веса, все 201 оценки по эпохам и итоговые
метрики. Время и метаданные при сравнении исключались. Это проверка
повторяемости в одном окружении, не гарантия совпадения на разных платформах.

Артефакты находятся локально в runs/go-prototype/ и
runs/go-prototype-repeat/, исключены из Git. Источники результата:
summary.json, history.json и сохранённые веса. Запуски выполнены до коммита,
поэтому environment.json содержит предшествующий Git-коммит и dirty=true.
Метаданные исходных запусков не менялись задним числом.

## Проверки и ограничения

- go test ./...: 10 основных тестов ядра, включая численные градиенты
  всей маленькой сети для четырёх активаций, и 3 теста уровня приложения.
- go vet ./... и сборка бинарного файла.
- Пакет из 65 примеров с неполным хвостом, сохранение/загрузка весов,
  запрет перезаписи существующих запусков, конфигурация и HTML-экранирование.
- Короткие CLI-запуски ReLU/SGD, tanh/Adam и Leaky ReLU/Adam;
  это проверки режимов, не исследования их качества.
- Данные и JavaScript отчёта проверяются tests/report-check.mjs:
  CSV, встроенный JSON, расстояния на карте, управление и статический резервный вид.

HTML-шаблон встроен в бинарный файл через go:embed. Реальное отображение
в браузере не проверено из-за запрета file:// встроенным Browser;
проверки JavaScript используют тестовые заменители DOM/Canvas.
Продолжение обучения из checkpoint не поддерживается.

Один опыт не доказывает преимущество глубины или Swish и не устанавливает
качество вне выбранного квадрата или на другом горизонте движения.
