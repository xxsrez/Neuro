# Первый опыт Neuro — 27 сентября 2026

## Результат

Маленькая глубокая сеть обучилась предсказывать конечное движение точки
и на новых точках превзошла обе контрольные модели. Заранее установленный
критерий валидационной MSE <= 0.01 достигнут. Это один эксперимент
со Swish и Adam, без доказательства превосходства глубины или активации.

| Модель | Валидационная MSE |
| --- | ---: |
| Сеть до обучения | 0.800276 |
| Предсказание без движения | 0.445082 |
| Аффинная модель, обученная на train | 0.416817 |
| Сеть, лучшие веса | 0.000363676497 |

Лучшие веса выбраны на эпохе 177. Их тестовая MSE — 0.000393134586,
среднее расстояние в исходных координатах — 0.0676282; на валидации
расстояние — 0.0658735. MSE считается по координатам, разделённым на pi.
Тест оценён после выбора весов по валидации.

## Конфигурация и метод

- C#/.NET 10, double, стандартная библиотека, один поток, явные циклы.
- Ширина 20, 10 двухслойных остаточных блоков, 20 внутренних/22 полных
  слоя, 8 502 параметра; Swish, alpha = 0.1, без BatchNorm.
- Независимые равномерные веса в пределах sqrt(6/(fan_in+fan_out)),
  нулевые смещения; SplitMix64, начальное состояние весов 42.
- 20 шагов симулятора с h = 0.2; входы из [-pi, pi]².
- 8 192 обучающих, 2 048 валидационных, 2 048 тестовых точек;
  начальные состояния генераторов 1001, 2002, 3003; перемешивание 4004.
- Adam, lr = 0.001, beta1 = 0.9, beta2 = 0.999, epsilon = 1e-8.
- 200 эпох, пакет 64, 25 600 обновлений. Полная оценка train/validation
  после каждой эпохи. Аффинная модель получена решением нормальных уравнений
  собственного небольшого решателя, только по обучающим данным.

Первый запуск train и оценка по эпохам заняли 53.36 секунды; это измерение
одного процесса в данном окружении, без включения генерации конечного HTML.
Время эпохи обучения после разогрева — около 0.19 секунды.
Точная ОС/runtime/архитектура записаны в environment.json каждого запуска.
Окружение: .NET SDK 10.0.401, runtime 10.0.12, macOS 27.0.0, Arm64.

Артефакты первого запуска находятся локально в runs/prototype/ и исключены
из Git. Публичной ссылки на отчёт нет. Числа выше получены из summary.json,
metrics.csv и повторной оценки загруженных best-weights.json.
Второй полный запуск находится в runs/prototype-repeat/: совпали все
метрики всех 201 оценок, лучшие и последние веса побитово после загрузки
JSON. Отличается время (53.60 секунды) и метаданные запуска. Повторяемость
подтверждена в одном окружении, не между разными платформами.

Запуски выполнены до коммита прототипа: environment.json содержит
предшествующий Git-коммит и dirty=true. Финальная реализация вычислений
соответствует проверенному коду; метаданные исходных запусков сохранены.

## Проверки и ограничения

Сборка без ошибок и предупреждений. Все 10 групп собственных тестов прошли:
генератор, активации, линейный слой, остаточный путь, полные численные
градиенты маленькой сети, пакеты, SGD/Adam, аффинная модель, восстановление
и воспроизводимость, обучение контрольной задачи.
Короткие проверки CLI для ReLU/SGD, tanh/Adam и Leaky ReLU/Adam завершены
с конечными числами, включая обучающий набор из 65 примеров и неполный
последний пакет. Они проверяют доступность режимов, а не их качество
или сопоставимость с полным опытом Swish.

Проверки HTML подтвердили соответствие встроенных данных и CSV, правильность
расстояний на карте, статическое содержимое, обработчики управления
и явный отказ интерактивного вида с сохранением основного отчёта.
DOM/Canvas использовали тестовые заменители. Реальное отображение страницы,
телефонная вёрстка и режим без JavaScript в браузере не проверены:
встроенный Browser отклонил file:// политикой безопасности. Обход запрета
не выполнялся.

Ошибка не падает монотонно: например, на эпохе 150 валидационная MSE
0.00556844, а на последней 200 — 0.000639118. Лучшие и последние веса
разделены; график сохраняет всплески. Этот опыт не устанавливает качество
вне обучаемого квадрата или для другого горизонта движения.

Следующий исследовательский этап — сравнения активаций, оптимизаторов
и глубины на нескольких начальных состояниях. Полное возобновление
обучения из checkpoint пока не поддерживается.
