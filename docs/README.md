# Документация Neuro

Реализован первый локальный прототип. Документы описывают текущую
конфигурацию, проверки и дальнейшие опыты. Стартовые настройки дали
работающий первый запуск, но их оптимальность не установлена.

- [Обзор проекта](overview.md) — цели, сценарий работы, предполагаемые
  компоненты и границы первой версии.
- [Первая задача: движение точки](specs/point-motion.md) — генерация данных,
  разделение выборок, нормализация и контроль сложности задачи.
- [Проект архитектуры](architecture.md) — предложение для согласования,
  размеры слоёв, нелинейность и прохождение градиента.
- [Обучение и оценка](training.md) — функция потерь, обратный проход,
  оптимизаторы, метрики, графики и воспроизводимость.
- [Предварительный план разработки](development-plan.md) — порядок работ,
  результаты этапов и критерии проверки.
- [Руководство по запуску](guides/running.md) — сборка, тесты, параметры
  и файлы результатов.
- [Первый опыт](reports/prototype-2026-09-27.md) — измеренные метрики,
  контрольные модели и границы проверки.

Для первого знакомства читать обзор, затем задачу и архитектуру.
Перед реализацией читать также обучение и план разработки.
Инструкции для агента находятся в [AGENTS.md](../AGENTS.md).

## Статус решений

Зафиксированы цель учебного стенда, CPU, собственное вычислительное ядро,
глубокая узкая сеть, одинаковая скрытая ширина, задача движения точки,
сравнение ReLU, tanh и Swish, функция потерь и графики её изменения.

Рабочая конфигурация: ширина 20, 10 двухслойных остаточных блоков, Swish
первой, Leaky ReLU дополнительно, без BatchNorm; размеры выборок и параметры
обучения сохранены в конфигурации каждого запуска.

Язык — C#/.NET 10, инициализация — равномерная по fan_in/fan_out,
визуализация — автономный HTML с SVG и Canvas. Десять блоков означают
20 внутренних и 22 полных обучаемых слоя; 9 блоков дают ровно 20 полных.
Оптимальные настройки и результаты серии сравнений остаются открытыми.
